# UNUSUALL

Каркас сайта бренда одежды и студии кастомной вышивки. Phase 3.1 добавляет дизайн-систему и стенд компонентов.

## Окружение и запуск

Используйте Node.js 24.x и npm 11.x. Каркас проверен в Windows с Node.js 24.11.1 и npm 11.6.2. Выполняйте команды из корня проекта в PowerShell.

```powershell
npm ci
npm run dev
```

По умолчанию приложение доступно на `http://localhost:3000`. Для этого этапа переменные окружения не требуются. В `.env.example` перечислены примеры для последующих этапов.

Откройте `http://localhost:3000/ui-kit` после `npm run dev`, чтобы проверить компоненты. В production-сборке этот адрес возвращает 404.

## Проверки

```powershell
npm run lint
npm run typecheck
npm run build
npm run start
```

`typecheck` сначала генерирует типы маршрутов Next.js. `start` запускает локальный сервер для сборки, созданной командой `build`. Перед `npm run start` остановите dev-сервер, если оба используют один порт.

## Структура

- `src/app/` — корневой layout, подключение Tailwind CSS и маршруты `/`, `/collection`, `/create-order`, `/about`.
- `src/components/ui/` — базовые компоненты и декоративные элементы.
- `public/` — графические ресурсы сайта.
- `design/` — исходные макеты.
- `docs/` — спецификации и [дорожная карта](docs/ROADMAP.md).
